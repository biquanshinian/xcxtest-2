# 热点稿：写 / 不写 / 标题

## 写（对过推荐）

**辟谣 / 辨假**

- 朱雀三号回收场爆炸图片系 AI 生成
- 这张「星舰爆炸」图对不上发射当天的天气和工位

结构：结论标题 → 图从哪来 → 哪几处对不上 → 以后怎么一眼看穿。

**关键节点贴图**

- 星舰 41 从梅西测试场返回星际基地（图是信息，说明两三段即可）

结构：标题报节点 → 1～3 张图 → 80～180 字。不要写成发射通稿。

## 不写热点（对过冷稿）

这些发了也是几十阅读，不要当「写热点」交卷：

- 蓝箭航天曝光天鹊-12B 发动机用于朱雀三号……
- 蓝箭航天目标六个月内复飞回收朱雀三号助推……
- 复盘 SpaceX 八月财报电话会：星舰想被接住……

改法：

| 通稿 | 能不能改成热点 |
|---|---|
| 公司曝光发动机 | 只有出现「和上次公开的不是同一台 / 图对不上型号」才写 |
| 目标六个月复飞 | 不写计划；等真正复飞或正式改期 |
| 财报复盘 | 默认 C（粉丝向），或只抽一句被传错的数字做 A |

## 标题

**要**

- 回收场那几张爆炸图是生成的
- 点火时间不是晚上七点，航警窗口在凌晨

**不要**

- XX 公司宣布 / 曝光 / 发布 / 目标……
- 复盘 XX 电话会 / 一文看懂八月财报
- 重磅、震惊、终于、官方最新消息（空钩子）

## 同题冷却

8.19 朱雀辟谣爆了，8.21–8.22 接着发蓝箭/朱雀新闻 → 60 左右。  
8.23 换成星舰贴图 → 再进池。

同一火箭或同一公司：推荐向稿间隔至少 4 天，或换成完全不同的判断句。
