## 发布注意
- 图内与正文避免写微信/小程序/链接/二维码硬引流
- 互动引导用「评论区留言场站+业态」
- 线上强调免费预约；收费服务表述保持线下合规
- 场站×火箭与 Logo 规范见项目技能 `.cursor/skills/xhs-watch-party-merchant/`
- **海射**（谷神星海射/引力一号等）默认 **海阳东方航天港**，勿写成文昌
- Logo 纠错：原图不动，只替换已有品牌区；无标跳过  
  `py -3 .cursor/skills/xhs-watch-party-merchant/scripts/replace_logo_inplace.py --all`  
  报告 `_logo_replace_report.csv`；备份 `_logo_backup/`
