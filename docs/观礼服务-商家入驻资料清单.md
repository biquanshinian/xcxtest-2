# 火箭观礼服务 · 商家入驻资料清单

> 给运营人员：新商家入驻时按本清单收集资料，收齐后按「后台操作路径」逐项录入即可开业。
> 给商家：请按「一、必填资料」逐项准备，坐标类资料可用地图截图 + 微信发位置的方式提供，运营会帮你复核。

---

## 一、必填资料（缺一不可）

| # | 资料项 | 要求 | 后台录入位置 |
|---|--------|------|--------------|
| 1 | 商家/观礼点名称 | ≤40 字，将对用户展示「观礼点由 xx 提供」 | 合作商家 → 商家入驻 |
| 2 | 联系人姓名 + 手机号 | 运营对接与紧急联络用 | 合作商家 → 商家入驻 |
| 3 | 观礼点详细地址 | 精确到门牌/楼栋，如「文昌市龙楼镇航天大道 ×× 号 6 栋」 | 合作商家（模板）/ 观礼场次 |
| 4 | 观礼点精确坐标 | 纬度/经度各 6 位小数，**腾讯坐标系（gcj02）**，见下方「坐标怎么取」 | 合作商家（模板）/ 观礼场次 |
| 5 | 停车点 1~3 个 | 每个：名称（P1/P2…）+ 坐标 + 步行分钟 + 备注；**必须在发射日交通管制圈外**，提前踩点确认 | 合作商家（模板）/ 观礼场次 |
| 6 | 场次信息 | 关联的发射任务、发射时间（以官方窗口为准）、预约容量上限 | 观礼场次 → 新增场次 |
| 7 | 楼顶安全确认 | 承载人数上限（决定预约容量）、护栏/照明情况、保险情况 | 记录在商家「合作备注」 |

### 坐标怎么取（三选一，推荐 ①）

1. **腾讯坐标拾取器（推荐）**：浏览器打开 `lbs.qq.com/getPoint`，搜索或拖动地图到观礼点楼顶位置，直接复制经纬度发给运营。
2. **微信发位置**：微信聊天 → 「+」→ 位置 → 长按地图选到观礼点 → 发送后**截图**给运营，运营用拾取器复核出坐标。
3. **地图 App 截图**：腾讯地图 App 长按选点，截图（带地点名）发运营复核。

⚠️ 坐标系三个坑：
- **不要用百度地图的坐标**（bd09 坐标系，会偏移几百米）；
- 手机 GPS 工具读出的原始 wgs84 坐标在国内地图上也有偏移，需转换；
- 小程序内导航用的是腾讯地图，所以一律以 **gcj02（腾讯/高德坐标系）** 为准。
- 停车点坐标同样要求：用户会点「一键导航」直接开过去，偏了就是投诉。

## 二、强烈建议提供（决定体验上限）

| 资料项 | 说明 |
|--------|------|
| 观礼介绍 | 视野方向、楼层高度、与发射工位距离、设施（卫生间/遮阳/座位）、最佳拍照机位；换行分段 |
| 观礼须知 | 安全要求、发射日交通管制提示、禁飞无人机、点火声震提示（约 30 秒后到达）、小孩看护提醒 |
| 大屏科普轮播 | 每行一条，推荐写成「标题\|正文」格式（如：`长征五号有多高？\|全长约57米，相当于20层楼`），大屏显示为大标题科普卡；建议准备 8~15 条，覆盖火箭型号、飞行时序、任务载荷 |
| 现场奖品素材 | 奖品实拍图建议 **正方形或 1:1、≥750px**；名称、库存数量、选填价值；每场建议 3~8 件，由商家在小程序自建 |
| 渠道码点位清单 | 想铺码的点位列表（民宿前台/接送司机/易拉宝/沙滩路牌…），每个点位单独生成渠道码，后台能看出哪个点位引流最多 |
| 大屏播放设备 | 安卓盒子/平板/电脑 + 显示屏，浏览器打开大屏页地址：`watch-screen.html?code=场次短码`，**点开就能用**。安卓设备三步：① 系统设置里把「自动息屏」调成永不；② 打开页面后轻触屏幕一次进入全屏；③ 讲解时轻触科普卡片可手动切下一条。大屏按倒计时自动切换阶段（签到→讲解→冲刺→升空），无需人工操作 |

## 五、运营侧备忘

- **一键关停**：观礼场次页顶部全局开关（终止合作用）；单商家暂停在合作商家页操作，其名下场次即时下线。
- **推荐入驻**：同行商家在观礼页提交合作申请后，在合作商家页「合作申请」列表跟进，通过后一键转商家档案（推荐关系自动落档）。
- **通行证配置**：每场次可单独开关、时长 1~72 小时可调（默认 24）；有发射时间的场次仅发射前后 48h 内发证。
- **隐私合规**：预约登记收集「姓名+手机号」，需在小程序管理后台《用户隐私保护指引》中声明（设置 → 服务内容声明 → 用户隐私保护指引 → 修改），否则审核可能被驳回。可直接使用以下文案：
  - **手机号**：用于火箭观礼活动的免费预约登记与到场核销。当发射时间变更、活动延期取消或有重要观礼提醒时，活动主办方可能通过该手机号与你联系。手机号由你在预约表单中主动填写，仅用于上述现场活动组织用途，不会用于营销推广，也不会对外提供。
  - **昵称/姓名**：用于火箭观礼活动预约登记，以及入场时工作人员核对预约信息。由你在预约表单中主动填写，可填昵称或称呼，不强制真实姓名。
- **数据看板**：场次「统计」弹窗看预约数/核销率/扫码人数/抽卡稀有度分布/渠道分布/通行证发放数。
- **走单统计（谈判依据）**：合作商家页每行「走单统计」按钮，跨场次汇总该商家的到场扫码单数（每人每场次记 1 单）、预约/核销/抽卡/通行证与渠道分布，按场次逐条列明细——和商家谈分成、续约时直接用这份数据。
