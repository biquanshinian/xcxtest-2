# 火星探索日志 · 小程序功能导航

文档版本：2026-09-07

「火星探索日志」（也叫空叉火星探索日志）是面向中文用户的航天追踪小程序：全球火箭发射倒计时、任务详情、星链过境、空间站动态、星舰进度、火箭族谱、型号对比与档案指数、3D 展厅、航天事件、天文日历，以及发射现场观礼服务。

微信搜「火星探索日志」即可打开。底部五个 Tab：**主页 / 监控 / 进展 / 事件 / 我的**。

---

## 小微和星问

| 名称 | 在哪 | 擅长 |
|------|------|------|
| **小微 / 微信 AI** | 微信主界面助手，调用本小程序 | 应打开火星探索日志对应页；发射/星舰/空间站/助推器可查实时数据 |
| **星问** | 小程序内助手 | 打开小程序之后再问；左上角放大镜进入，不是搜索 |

星问入口：多数 Tab 页左上角放大镜，或右侧悬浮圆盘「星问AI」。过审关闭时入口会隐藏，不要说一定能打开。

## 五个 Tab

### 主页（发射追踪）

全球即将发射倒计时与列表。今天打不打、几点打，以首页当前显示为准。列表上方有发射商胶囊：「所有任务」都可以看，筛某一家可能要星际通行证。点任务卡进详情。也有发射日历、历史发射、直播入口。

- 路径：`pages/index/index`

### 监控中心

视频号 / B 站直播入口、星链过境（需大致位置）、星链实时分布、空间站状态、可回收火箭族谱预览、全球飞船图鉴、全球发射场分布、全球发射商图鉴、在轨飞行器追踪入口。

- 问「今晚星链过境」「天宫上有谁」「哪家发射商」→ 监控中心或对应详情。
- 路径：`pages/monitor/monitor`

### 进展（星舰进度）

SpaceX 星舰组合体与硬件、事件更新、Starbase 地图、道路封闭。星舰助推器编号常见为 B15 / B16 这类，与猎鹰助推器 B1067 不是同一套。

- 路径：`pages/progress/progress`

### 事件

三个子页：**航天摄影**（开关开启时默认落在这里）、**航天事件**（手写稿和资讯只在这里）、**即将发生**。摄影开关关闭时才回退到航天事件。

- 路径：`pages/news/news`
- 文章/事件详情：`subpackages/news-extra/detail`（必填 `id`、`type`=`article` 或 `event`）
- 摄影详情：`subpackages/news-extra/photo-detail`；投稿用事件页「投稿」按钮，不要伪造上传入口。

### 我的

签到、成就徽章、发射竞猜、每日挑战、收藏、年度回顾、星际通行证（会员）、**火箭发射观礼**入口。

- 路径：`pages/profile/profile`

## 发射与任务

**任务详情**：倒计时、窗口、火箭、发射场、发射商、直播与回放、回收信息。火箭名可进型号档案；头图在有模型时提供 3D / 360 环绕；右下可进「型号对比」「档案指数」。

- 路径：`pages/mission-detail/mission-detail`
- query：`id`（任务 UUID，必填），`type`=`upcoming`（默认）或 `completed`

**全球发射统计**：年度次数、成功/失败、国家 / 发射商 / 型号排行。可从星问统计卡进入。

- 路径：`subpackages/index-extra/global-launch-stats`

**搜索**：搜发射任务、机构、火箭型号。从星问卡片「更多」进入，**主页左上角放大镜是星问，不是搜索**。路径：`pages/search/search`，query 可用 `q`。

**发射集锦 / 飞行剖面 / 任务指挥室**：任务详情或相关演示页内查看，勿编造视频内容。飞行剖面：`subpackages/mission-sim/mission-sim`。

## 火箭档案、对比、评分、3D

### 火箭型号详情

公开参数（全长、直径、运力、推力、复用、发射战绩等）与关联助推器。从任务详情点火箭名，或从族谱 / 搜索进入。

- 路径：`subpackages/monitor-pages/rocket-model-detail`
- query：`configId`（LL2 构型 id，必填）

### 火箭型号对比

并排对比 2–4 款：尺寸、运力、推力、复用、发射与回收战绩。入口：任务详情对比按钮、型号详情、族谱页。可能需要星际通行证或看广告，以页内提示为准。

- 路径：`subpackages/monitor-pages/rocket-compare`
- query：`ids` 为构型 id，逗号分隔，最多 4 个（如 `164,215`）。无 `ids` 时打开选型。

### 火箭档案指数

按同量级把运力、动力、经济性、可靠度、复用、成熟度折成约 1–5 分，**不是投票，也不是权威排名**。缺公开参数的维度会空着，不要补数字。

- 路径：`subpackages/monitor-pages/rocket-score`
- query：`configId`（必填），可选 `name` / `nameEn`
- 入口：任务详情「档案指数」按钮。可能需通行证或看广告。

### 3D 火箭展厅

部分型号可旋转查看 3D 模型。入口：任务详情头图「三维」、型号详情。不是每型都有；没有就说暂未提供，不要承诺任意火箭都能看。可能需星际通行证。

- 路径：`subpackages/rocket-3d/viewer`
- query：优先 `slug` 或 `configId`，可选 `name` / `nameEn`

### 可回收火箭族谱 / 助推器

猎鹰及全球可回收助推器：飞行次数、复用、着陆历史。点编号进单枚战绩。问「B1067 飞了几次」应进助推器详情或查实时战绩，不要猜次数。

- 族谱：`subpackages/monitor-pages/booster-genealogy`
- 单枚：`subpackages/monitor-pages/booster-detail`，query：`serial`（如 `B1067`）

## 发射商、飞船、发射场、空间站

- **发射商图鉴**：`subpackages/monitor-pages/agency-list`
- **发射商详情**：`subpackages/monitor-pages/agency-detail`，query：`id`（如 SpaceX 为 `121`）
- **飞船图鉴**：`subpackages/monitor-pages/spacecraft-gallery`
- **发射场分布**：监控中心图鉴；地图 `subpackages/monitor-pages/launch-site-map`
- **空间站详情**（ISS / 天宫等）：`subpackages/monitor-pages/station-detail`，query：`id`
- 在轨人数、乘组以空间站页面当时显示的为准。

## 星链与观测

- **过境预报**：监控中心，需授权模糊位置，用于计算方位、仰角、方向。不授权就无法给出「今晚能否看见」的具体时刻。
- **过境地图 / 全屏**：`subpackages/monitor-pages/pass-map`、`subpackages/monitor-pages/starlink-fullscreen`
- **星链 AR**：`subpackages/monitor-pages/starlink-ar/starlink-ar`（监控中心进入）
- **星座分布 / 轨道数据**：监控中心与 `subpackages/monitor-pages/orbital-data-center/orbital-data-center`
- 在轨颗数以页面为准，不要背数字。

## 星舰、封路、航警、在轨追踪

- 星舰进度 Tab：组合体、硬件、动态。
- Starbase 地图：`subpackages/progress-extra/starbase-map`
- 封路列表/地图：`subpackages/progress-extra/road-closure-detail`、`subpackages/progress-extra/road-closure-map`；勿编造封路时段。
- 中国空间航警：`subpackages/monitor-pages/space-notices/entry-list`
- 在轨飞行器追踪：`subpackages/monitor-pages/vehicle-tracker/vehicle-tracker`
- Artemis / 罗马望远镜等专题：`subpackages/monitor-pages/artemis-detail`、`subpackages/monitor-pages/roman-detail`，只陈述页内信息。

## 火箭观礼

面向文昌等发射场的现场观礼：看商家场次、预约、现场说明。入口：**我的 → 发射观礼**，或星问里问「去哪看发射 / 文昌观礼」点观礼卡片。

- 商家/场次列表（无具体场次时用这个）：`subpackages/watch-party/merchant-list`，可选 `missionId`、`channel`
- 某一场详情：`subpackages/watch-party/watch-party`，需要 `sessionId` 或现场码 `code`；没有则应落到列表，不要假装已约上。

硬性规则：

- 场次时间、地点、费用、是否满员，以进入观礼页之后显示的为准。
- 功能关闭时，入口会看不到。

## 会员与门控（被问再答）

星际通行证可以解锁部分深度页（族谱、对比、档案指数、3D）。有的也可以看广告试用。价格以支付页为准。非会员看视频时，多数先看到封面。
