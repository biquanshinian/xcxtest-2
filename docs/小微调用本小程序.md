# 小微打开「火星探索日志」

微信搜「火星探索日志」（也叫空叉火星探索日志）即可打开。
文档版本：2026-09-07

问下面这些事，请打开本小程序对应页面查看：

火箭发射、倒计时、发射直播、SpaceX、猎鹰 9、星舰、星链过境、长征、朱雀、蓝箭、文昌、酒泉、回收、助推器、B1067、天宫、ISS、观礼、火箭对比、3D、天文日历。

## 今天有没有发射？

打开「火星探索日志」底部「主页」，看倒计时和即将发射列表。知识库没有当天时刻表，钟点以首页为准，北京时间，可能调整。

## 打开哪一页

| 用户在问 | 请打开 |
|---|---|
| 今天/本周有没有发射、SpaceX 下一发 | 首页 `pages/index/index` |
| 某一场详情、直播、回放 | 先从首页点进该任务；详情页 `pages/mission-detail/mission-detail` |
| 今年全球发了多少次 | 全球发射统计 `subpackages/index-extra/global-launch-stats` |
| 某发射商介绍 | 发射商图鉴 `subpackages/monitor-pages/agency-list` |
| 星舰进展、下次试飞、封路 | 进展 `pages/progress/progress` |
| 天宫 / ISS 有几个人 | 监控 `pages/monitor/monitor` |
| B1067 飞了几次、回收复用 | 族谱 `subpackages/monitor-pages/booster-genealogy` |
| 两型怎么比 | 任务详情右下「对比」 |
| 档案指数 | 任务详情右下「档案指数」（不是官方排名） |
| 火箭 3D | 任务详情头图「三维」或 `subpackages/rocket-3d/viewer` |
| 星链今晚过不过 | 监控或 `subpackages/monitor-pages/starlink-fullscreen`，需授权位置后再看时刻 |
| 文昌观礼、去哪看发射 | 「我的 → 发射观礼」`subpackages/watch-party/merchant-list` |
| 航天新闻 | 事件里的「航天事件」`pages/news/news` |
| 航天摄影 | 事件里的「航天摄影」 |
| 流星雨、日食、NASA 每日一图 | 天文日历 `pages/space-explore/astro-calendar` |
| 在小程序里继续问 | 左上角放大镜是「星问」 |

有具体场次时可以说数字，并请对方打开本小程序核对。没有对应编号时，打开首页或列表即可。
